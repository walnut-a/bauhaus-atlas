01

包豪斯，到底指什么？

包豪斯是 1919 年在德国创办的一所艺术与设计学校，创办人是建筑师沃尔特·格罗皮乌斯。它先后在魏玛、德绍和柏林办学，1933 年关闭。今天人们常把它当作一种风格来谈，但它最初是一所探索“怎样设计”的学校。[01][22]

在这里，画画、做家具、织布和设计建筑被放到了一起。学生既学习颜色和形状，也亲手制作物品。学校早期重视艺术与手工艺的合作，后来更关注机器生产，以及日常生活中人们真正需要什么。[01][13]

A

历史上的学校

1919—1933 年间实际存在的学校。钢管椅、台灯、织物与舞台实验，来自这里不同的老师、学生和工作坊。

B

流传下来的方法

先试一试材料能做什么，再考虑物品怎样使用、怎样制作。今天的设计仍然可以借鉴这种做法。

C

今天的视觉标签

今天常说的“包豪斯风”，通常指几何形、红黄蓝和简洁的字体。这是对一部分作品外观的概括。

02

这所学校，经历了怎样的变化？

从手工艺到机器生产，包豪斯的教学重点一直在变化。

weimar
01 / 从工艺共同体出发

从艺术与手工艺开始

1919 年，格罗皮乌斯希望艺术家与工匠一起工作。学生画画，也做木工、织布、研究颜色与材料。1923 年的展览提出“艺术与技术的新统一”，学校开始更积极地思考艺术怎样与工业生产结合。[01][04][13]

索默菲尔德住宅里有木雕、彩色玻璃和织物，能看出这个时期对手工艺的重视。看看这座住宅 →

dessau
02 / 与产业和社会需要接触

让设计走进工厂与日常生活

1925 年，学校迁往德绍，第二年启用新校舍，1927 年开设正式建筑课程。1928 年接任校长的汉内斯·迈耶，更关心人们需要怎样的房子和物品，以及怎样降低成本。他与团队设计的伯尔瑙工会学校，是这一思路的代表。1930 年，密斯·凡·德·罗接任校长。[09][20][22]

这一时期的作品包括钢管家具、灯具、织物、住宅和公共建筑。它们逐渐面向工业生产，也仍有手工制作与试验样品。

berlin
03 / 最后的办学阶段

学校关闭，不代表影响停止。

受到政治压力后，包豪斯于 1932 年迁往柏林，1933 年在纳粹当局的压力下关闭。办学时间虽然只有十四年，教师和学生此后仍在其他地方继续工作与教学。[01][22]

三任校长的任期

格罗皮乌斯 1919–1928 → 汉内斯·迈耶 1928–1930 → 密斯·凡·德·罗 1930–1933 [22]

03

学生怎样学习设计？

学生先从基础课学习颜色、形状和材料，再进入木工、金属、织造、印刷等工作坊。一边观察，一边制作，是教学的重要特点。伊顿最早主持基础课，后来莫霍利–纳吉、阿尔伯斯等人继续发展课程，内容也随教师和时期而变化。[03]

观察 / 基础课

观察颜色与形状

同一块红色，放在白底和黑底上，看起来一样吗？一条斜线和一条横线，给人的感觉有什么不同？

制作 / 工作坊

亲手试一试材料

纸折过以后会不会更结实？线织得更密，摸起来会怎样？动手做，才能发现材料的特点。

协作 / 综合项目

一起完成一件作品

设计一个房间时，灯、家具、窗帘和墙面颜色要一起考虑。不同工作坊的学生，也会一起参与建筑和室内设计。

建筑一直是包豪斯希望综合多种艺术的领域，不过正式建筑课程到 1927 年才开设。[03]

一个纸张小练习

拿一张纸，不画装饰，先让它承起一个小物体。折一次、卷一次、开一道切口，分别比较稳定性与用料。然后把问题换成“让它在侧光下产生不同阴影”，你就会发现同一种材料能回应不同目标。

先提出一个问题，动手尝试，再根据结果调整。这样的练习关注材料能做什么。还可以看看 Getty 介绍的阿尔伯斯纸张练习。[18]

04

为什么包豪斯不等于极简？

看一看下面的台灯和壁毯：一个简洁，一个色彩丰富。两者都与包豪斯有关。

椅子要承托身体，
舞台服装要塑造形象。

用途不同，设计的样子也会不同。

台灯用清楚的几何形组织灯罩、灯杆和底座；壁毯让曲线、色块和纹理交错。包豪斯既研究实用物品，也重视色彩与艺术表达。

日常说“极简”，通常是指看起来简洁、元素少。艺术史中的“极简主义”则主要发展于 1960 年代，比包豪斯晚了几十年。两者有联系，却属于不同的历史背景。[16][23]

包豪斯的一些家具和建筑减少了传统装饰，强调材料与制造方式；织物和舞台作品却可以充满颜色、纹理和夸张轮廓。这些领域要解决的问题本来就不同。[07][08][14]

“构成”就是怎样安排形状、颜色和位置。例如，把圆盘放在脖子周围，会改变整个人形的轮廓；画上条纹，会让视线沿着身体移动。这样的安排可以产生装饰效果，装饰与构成也可以同时存在。

从八件作品看懂包豪斯

01
建筑1925–1926

德绍包豪斯校舍

Walter Gropius 及其事务所

教学、工作、居住，各有空间，又由走廊和连桥联系起来。

看看设计细节 ＋

工作坊、教学、行政和住宿并没有被塞进一个对称的外壳。不同高度的体块与连桥，让各部分既独立又关联；玻璃幕墙则改变了墙体、光线和视线的关系。校舍于 1926 年启用，由格罗皮乌斯的私人事务所负责设计，并有学校各工作坊参与室内配置。[09]

留意玻璃立面和连桥。大片玻璃让工作空间获得光线，也让建筑显得通透。不同的建筑部分通过连桥相接，室内也用了颜色来区分空间。[09]

02
家具1925

瓦西里钢管椅（B3）

Marcel Breuer · 马塞尔·布劳耶

用弯曲的钢管做骨架，用绷紧的布或皮革做坐面、靠背和扶手。

看看设计细节 ＋

布劳耶看到自行车钢管轻而结实，把这种材料用在椅子上。钢管弯成骨架，布或皮革悬在骨架之间，支撑身体。大都会博物馆收藏的一件实例使用镀铬钢管与帆布；皮革版是另一种常见版本。[10]

顺着钢管看它怎样支撑人。坐面、靠背和扶手分开悬在骨架上，中间留下了空隙，所以椅子看起来轻盈、通透。

皮革版更容易看清坐面、靠背与扶手各自的位置。可以和上方的侧面照片对照着看。

灯具1924

瓦根费尔德台灯

威廉·瓦根费尔德 · 承接卡尔·雅各布·尤克尔的设计探索

圆底座、细灯杆、半球灯罩：几种简单形状，组成一盏台灯。

看看设计细节 ＋

织物1927–1928

红／绿壁毯：丰富也是一种答案

Gunta Stölzl · 贡塔·斯托尔茨尔

曲线、阶梯、棋盘格和流苏，织出丰富的图案与触感。

看看设计细节 ＋

这件壁毯里，波浪线、锯齿、棋盘格和大色块同时出现。边缘的流苏和表面的纹理，让它既可以用眼睛欣赏，也让人联想到织物的触感。

包豪斯的织造工作坊还研究怎样重复生产图案。例如另一件作品《Five Choirs》涉及提花织造——用织机控制经纬线，织出预先设计的花纹。[14]

字可以转向，圆弧与斜线也能帮助安排展览信息。

07
舞台1922 首演

《三元芭蕾》

Oskar Schlemmer · 奥斯卡·施莱默

球、圆盘和宽大的服装，让舞者的身体呈现出新的轮廓。

看看设计细节 ＋

《三元芭蕾》于 1922 年在斯图加特首演，有三幕、三位舞者和多套服装。这部作品在包豪斯之外形成，也与施莱默在学校的舞台教学紧密相连。服装改变了舞者的轮廓，也影响身体怎样转动和行走。[07]

看圆盘、条纹和膨大的服装。熟悉的人体被重新组合成几何形，金属反光和色彩又加强了舞台效果。照片拍的是 2017 年的博物馆展陈。

07

同样三个形，为什么感觉不同？

把形状放大、拉开，或换一种颜色，看看你的目光会先落在哪里。

试着调整形状与颜色
形状与颜色几何练习
配色

试着只改一个选项，比较画面有什么变化。

包豪斯的基础课研究点、线、形状和颜色，以及它们怎样影响人的感觉。康定斯基也曾探索颜色与形状的对应关系，这些探索成为了他的教学内容。[06][19]

把三个形状靠近，会更像一组；拉开后，各自就更独立。换成黑白，颜色的差异消失了，明暗的差异会更明显。这就是在观察“构成”：元素怎样摆放，会改变整体感受。

08

舞台上的人，为什么变成了几何形？

施莱默把人体看作可以重新组合的形状：头可以是椭圆，躯干可以是球，肩部可以围上一圈圆盘。服装一变，人的轮廓和动作也跟着变。舞台上要探索的是身体、服装与空间的关系。[07]

先看轮廓

圆球一样的躯干、圆盘状的领圈和宽大的下摆，让身体看起来像由几何体拼成。

再看装饰

条纹引导视线，鲜明的色块分开身体各部分，反光表面让人形显得更像机器。

想象它怎样移动

穿上宽大的服装，转身、抬手和行走都会呈现不同的样子。照片展示的是后来重建的舞台形象。

看一看：从人体到几何人形
人体、几何与服装人形变化示意

先看身体的轮廓

头、躯干和四肢组成了熟悉的人形。接下来，把它们换成简单的几何形。

这也解释了为什么一些装饰丰富的当代玩偶会让人联想到包豪斯：它们可能接近施莱默的几何人形和舞台服装。圆盘、球体、条纹和鲜艳的颜色，都能成为这种联系的线索。

如果设计者明确提到施莱默或《三元芭蕾》，就能进一步了解他引用了哪些部分。仅凭外形相似，还不能确定某个玩偶的设计来源。

09

看到“包豪斯风”，可以怎样理解？

常见说法通常指什么与包豪斯的关系
“这个东西很极简”形状、颜色或装饰比较少。简洁是一种外观特点，很多设计传统都有。
“它用了几何与原色”用了圆、方等形状，以及红、黄、蓝。包豪斯会使用这些元素，风格派等也会。
“它采用材料实验的方法”通过折、弯、织等尝试，了解材料。与包豪斯的学习方法有相通之处。
“作者明确引用施莱默”设计者说明自己参考了施莱默。可以对照具体作品，看看借用了哪些想法。

包豪斯是现代设计的重要来源之一。风格派是另一个常见名称，也会使用几何形与原色；极简主义则有更晚的艺术史背景。看起来相近的作品，可能来自不同的人和思路。[16][17]

所以，“包豪斯风”可以作为描述外观的起点。想了解得更深，就再看看作者、年代，以及它具体参考了哪件作品。

今天做设计，可以学到什么？

以设计一把椅子为例：谁来坐？它放在哪里？用木头还是钢管？材料怎样弯折、连接，才能承托身体？考虑这些问题，比直接套用红黄蓝更接近对设计方法的学习。

材料、用途和制作方式，会帮助你确定外形；但比例、色彩和触感仍然需要选择。同一个问题，可以有不同的好答案。

10

它影响了现代设计，也有自己的局限

理想与现实 01

希望服务大众，产品却未必便宜

包豪斯希望通过工业生产让更多人用上好的设计，但不少作品仍是手工样品。布兰特的茶浸器当时没有大规模量产，简洁的外观也不意味着成本低。[02]

理想与现实 02

女性作出了贡献，也受到限制

女性学生并不能平等进入所有工作坊，许多人被引向织造部门。斯托尔茨尔、安妮·阿尔伯斯等人的成就，也是在这样的限制下取得的。[02]

理想与现实 03

实用需求不会自动决定外形

同样是照明，灯罩可以有不同的大小和材质；同样是坐，椅子也可以有不同的比例和触感。功能提供了条件，设计者还要作出选择。

理想与现实 04

它的影响传开，也与其他传统交汇

教师和学生把教学与设计方法带到其他国家，这些方法又与当地文化、产业和设计传统结合。现代设计由许多这样的交流共同形成。[15]

从作品继续想下去

一件物品的样子，
可以从材料和用途开始理解。

下次看到一把椅子、一盏灯或一块织物，可以看看：它怎样制作，怎样使用，颜色和形状又带来什么感受。这些具体的观察，会让设计变得更容易理解。
