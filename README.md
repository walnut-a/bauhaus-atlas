# 包豪斯图谱 · Bauhaus Atlas

一份从真实作品出发的中文包豪斯视觉读本，介绍学校历史、教学方法、人物、建筑、家具、织物与舞台实验，并解释为什么包豪斯不等于极简主义。

在线阅读：<https://walnut-a.github.io/bauhaus-atlas/>

## 内容

- 12 个章节、8 组作品解析、11 张实物照片与历史图像。
- 章节目录、全文搜索、历史时间线、作品筛选、图片查看器和阅读测验。
- 两个默认折叠的几何教学实验。
- 参考资料，以及逐项列出的图片作者、来源、拍摄年代和许可。

## 本地预览

直接打开 `docs/index.html`，或者在仓库根目录运行：

```sh
python3 -m http.server 8000 --directory docs
```

然后打开 <http://localhost:8000>。网站无需安装依赖或构建，照片按原始版本从 Wikimedia 在线加载。

## 部署

GitHub Pages 使用 `main` 分支的 `/docs` 目录；向该目录提交并推送后自动更新。

## 来源与图片许可

本仓库最初恢复自《解释包豪斯理念》对话中的实物图像版成果（2026-09-25）。之后面向没有聊天背景的读者梳理了正文与界面文字，保留实物图片、来源资料和主要交互。后续内容维护约定见 `EDITORIAL.md`。

第三方图片保留各自许可，不适用统一的仓库许可。作品信息、图片署名、来源链接及许可详见网站末尾的“参考资料与图片来源”。
